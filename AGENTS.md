## Conventions

### General
- **Package manager:** pnpm (monorepo with workspace protocol)
- **Language:** TypeScript (strict mode)
- **Linting:** ESLint (per-app configs)
- **Line endings:** LF

### Naming
- **Files:** kebab-case (`meal-records.tsx`, `bazar-purchases.ts`)
- **Components:** PascalCase (`MealCard.tsx`, `BazarEntryForm.tsx`)
- **Zustand stores:** descriptive, e.g. `use-auth-store.ts`, `settings-store.ts`

### Mobile (Expo/React Native)
- **Navigation:** Expo Router (file-based, `Stack` + `Tabs`)
- **State (server):** TanStack Query (`useQuery`, `useMutation`)
- **State (client):** Zustand (simple global UI state only)
- **Forms:** React Hook Form + Zod resolver
- **Theme:** Expo `ThemeProvider` with `DefaultTheme`/`DarkTheme`
- **Fonts:** Poppins (headings/body), Hind Siliguri (Bangla text)
- **Icons:** `@expo/vector-icons` (MaterialCommunityIcons, Ionicons)

### Admin (Next.js)
- **Routing:** Next.js App Router (server components where possible)
- **Styling:** Tailwind CSS v4 (no config file — just `@import "tailwindcss"`)
- **Components:** Build on top of Tailwind primitives; shadcn/ui patterns acceptable
- **Forms:** React Hook Form + Zod
- **Tables:** TanStack Table

### Database (Supabase)
- **Migrations:** Sequential SQL files in `supabase/migrations/` (format: `YYYYMMDDHHMMSS_description.sql`)
- **IDs:** UUID v4 for all entity tables
- **Timestamps:** `created_at`, `updated_at` (UTC, `DEFAULT now()`)
- **Soft deletes:** Use `deleted_at` column where needed
- **RLS:** Enabled on ALL user-facing tables; policies per-feature
- **Money:** Store as `INTEGER` (BDT paisa, no decimals) to avoid floating-point errors

### API / Business Logic
- **Simple CRUD:** Supabase client directly (RLS enforced)
- **Complex/writer business logic:** Supabase Edge Functions (Deno)
- **Rate limiting:** Supabase Edge Functions + Upstash Redis

## Run / Build / Test Commands

```bash
# Root (monorepo)
pnpm install           # Install all workspace dependencies
pnpm build            # Build all apps
pnpm typecheck        # TypeScript check all apps
pnpm lint             # Lint all apps
pnpm test             # Run tests all apps

# Mobile (Expo)
cd apps/mobile
pnpm start            # Start Expo dev server
pnpm android          # Build/run on Android
pnpm web              # Run web version
pnpm typecheck        # Mobile TypeScript check

# Admin (Next.js)
cd apps/admin
pnpm dev              # Start Next.js dev server
pnpm build            # Production build
pnpm typecheck        # Admin TypeScript check

# Supabase (local)
supabase db push      # Push migrations to local
supabase db reset     # Reset local database
supabase functions serve  # Serve Edge Functions locally
```

## Verification Method
- **Mobile:** Manual test on Android device/emulator via Expo; TypeScript + Expo lint
- **Admin:** Manual in browser (localhost); TypeScript + ESLint
- **Database:** Migration validation via `supabase db push --dry-run`

## Current Feature Stack

### Mobile App Features
- Authentication (email/password, Google Sign-In)
- Onboarding flow
- Home dashboard (personalized greeting, quick actions, deadlines)
- Explore (opportunities: internships, scholarships, events, workshops, tuition, mentorship)
- Communities (join, post, comment, react, poll, event discovery)
- Saved/bookmarked opportunities
- Portfolio (skills, projects, certificates, achievements, research, resume)
- Notifications inbox
- Profile management
- To-Let listings (rental housing)

### Admin Panel Features
- Dashboard (KPIs, charts)
- Opportunity management (CRUD + review + publish workflow)
- Community management (posts, comments, moderation)
- Tuition/tutor management
- Education institution management (Khulna region schools/universities)
- Master data (categories, skills, subjects)
- Notification management
- User management (view, suspend, roles)
- Settings
- To-Let management

### Backend
- Supabase Auth (email + Google)
- PostgreSQL database with RLS
- Storage buckets (avatars, certificates, resumes, opportunity images, community media, tolet images)
- Edge Functions (community-actions, tolet-actions)
- Full-text search (PostgreSQL tsvector)
- Push notifications via Expo

## Timezone
- **System timezone:** Asia/Dhaka (Bangladesh)
- **Storage:** All timestamps stored as UTC in PostgreSQL
- **Display:** Convert to Asia/Dhaka for business logic (meal cut-offs, dates) and UI display
- **Important:** Meal cut-off times, bazar dates, monthly closing all operate on Bangladesh local time
